## A. 事前の準備（5分・1回だけ）

### A-1. クチコミ投稿用リンクを取得する

1. 森下様のGoogleアカウントで、Google検索に「マイビジネス」または事務所名を入力
2. 上部に出る自分の店舗の管理パネルで **「クチコミを増やす」**（または「クチコミをリクエスト」）をクリック
3. `https://g.page/r/……/review` という短いリンクが表示されるので **「リンクをコピー」**

このリンクを開くと、**星の入力欄が最初から開いた状態**でお客様の画面に出ます。ここが一番の脱落防止になります。
（「Googleで検索して探してください」だと、半分以上の方が途中でやめます）

> **リンクをこちらへお送りいただければ、印刷して受付に置ける QRコード付きのご案内カード（A5）をお作りします。**
> 郵送物・決算書のお渡し時に一緒に添えていただけます。

### A-2. 送る順番を決める

いきなり全顧問先へ一斉送信はしないでください。**Googleは短期間の急増を不自然と判断してクチコミを非表示にすることがあります。**

- **週に2〜3件ずつ**、6〜10週かけて送る
- 送る順番は「満足度が高いと分かっている先」から
- 目標はまず **10件**（10件を超えると地図検索での見え方が変わります）

### A-3. 送るタイミング（ここが成否の8割）

**満足度が最も高い瞬間の翌日以内**に送ります。

| タイミング | 対象 |
| --- | --- |
| 決算・申告が完了して申告書をお渡しした直後 | 法人・個人事業の顧問先 |
| 確定申告の還付が確定した直後 | 個人のお客様 |
| 年末調整・算定基礎届が終わった直後 | 社労士業務の顧問先 |
| 相続税申告が完了した直後 | 相続のお客様 |
| 補助金・助成金が採択された直後 | 該当先 |
| 顧問契約1年・3年の節目 | 継続顧問先 |

## C. お客様へ一緒に送る「書き方ガイド」

**B の文面のすぐ後に、続けてこの1通を送ってください。**
「何を書けばいいか分からない」が最大の脱落理由で、これがあると投稿率がはっきり上がります。

```
【書き方のご参考】

書くことに迷われたら、下の4つのうち答えやすいものだけで大丈夫です。
2〜3行、30秒で書けます。

① どんなことで困って相談されたか
　例：「開業したばかりで、何から手をつければいいか分からなかった」
　　　「前の税理士から返事がなかなか来ず困っていた」

② 何をお願いしたか
　例：「記帳代行と決算」「法人設立」「相続税の申告」「就業規則の作成」「給与計算」

③ 実際どうだったか（いちばん大事です）
　例：「質問への返事が早い」「専門用語を使わず説明してくれる」
　　　「税金だけでなく労務もまとめて相談できて助かっている」

④ どんな方におすすめか
　例：「これから起業する方に」「税理士を変えようか迷っている方に」

―――――――――――――――
【そのまま参考にしていただける例文】

〈例1〉
法人設立から記帳代行、決算までお願いしています。こちらが専門用語を分からなくても、
かみくだいて説明してくださるので毎回助かっています。質問しても当日か翌日には返事をいただけます。
これから会社を作る方には安心しておすすめできます。

〈例2〉
税務と労務の両方を一つの窓口でお願いできるのがありがたいです。
給与計算と社会保険の手続きもまとめて見ていただけるので、社内の負担がかなり減りました。
従業員が増えてきた会社さんには特に良いと思います。

〈例3〉
相続の手続きで初めてお願いしました。何も分からない状態でしたが、
必要な書類を一つずつ教えてくださり、想像していたよりずっとスムーズに終わりました。
落ち着いて話を聞いてくださる先生です。
―――――――――――――――

※ 会社名やご事情など、書きたくないことは書かなくて結構です。
※ 感じたままをそのままお書きください。良い評価をお願いするものではありません。
```

## D. 必ず守っていただきたいルール（違反するとクチコミが消えます）

| やってはいけないこと | 理由 |
| --- | --- |
| **顧問料の割引・商品券・粗品と引き換えにクチコミを依頼する** | Googleポリシー違反（クチコミ削除・プロフィール停止）。加えて景品表示法のステマ規制違反となり、消費者庁の措置命令の対象になり得ます |
| **「星5でお願いします」「良い評価でお願いします」と伝える** | 内容の指定は「事業者の表示」とみなされ、ステマ規制の対象。Googleも評価の操作として扱います |
| **満足度の高い人にだけリンクを送る仕組みを作る（アンケートで高評価者だけ誘導する等）** | 「レビューゲーティング」としてGoogleが明確に禁止しています。※ 順番を工夫するのは問題ありませんが、低評価の方に「書かないでください」と伝えるのはNGです |
| **文面をこちらで用意して「これを貼ってください」と渡す** | 実体験に基づかない投稿になります。上のC は**あくまで書き方の例**としてお渡しください |
| **事務所のパソコン・Wi-Fiで代わりに投稿する** | 同一IPからの投稿はGoogleに検知され、まとめて削除されます |
| **一度に何十件も送る** | 短期間の急増は不自然と判定され、非表示になることがあります（週2〜3件が安全です） |

### 逆に、必ずやっていただきたいこと

- **投稿には必ずオーナー返信をする**（できれば3日以内）。返信率はGoogleの評価にも、見た人の印象にも効きます
- 返信は定型文にせず、内容に触れて一言添える
  - 例：「〇〇様　このたびは温かいお言葉をありがとうございます。就業規則の件、その後も気になる点がございましたらいつでもご連絡ください。今後ともよろしくお願いいたします。」
- **低評価がついても削除依頼を急がない**。誠実な返信をしている事務所は、かえって信頼されます
