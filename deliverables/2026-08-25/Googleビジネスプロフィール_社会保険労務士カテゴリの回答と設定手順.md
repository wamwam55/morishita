# Googleビジネスプロフィール「社会保険労務士」カテゴリについて

作成日: 2026-08-25 ／ 作成: MIKANOS AI ／ 宛先: 森下知幸税理士・社労士事務所 森下 知幸 様

## 1. 結論

**「社会保険労務士」というカテゴリはGoogle側に存在しません。したがって、その名前で登録する方法はありません。**

現在お使いの **「社会保障事務所」が、実在するカテゴリの中では最も近い選択**です。設定自体は間違っていません。

### 根拠（実際に調べた結果）

| 確認したこと | 結果 |
| --- | --- |
| 公開されているGoogleビジネスプロフィールのカテゴリ全一覧（4,195件）を取得して全文検索 | 「社会保険労務士」「社労士」「労務」を含むカテゴリは **0件** |
| 「社会保障」で検索 | 「社会保障事務所」「弁護士（社会保障）」「社会保障財政課」の3件のみ |
| 他の士業カテゴリの有無 | 「税理士」「公認会計士」「行政書士」「司法書士」「法律事務所」「会計事務所」は存在する（社労士だけ無い） |
| Google公式ヘルプ「業種を管理する」の記載 | **「ご希望の具体的なカテゴリがない場合は、ビジネスを説明する一般的なカテゴリを選択してください。独自の業種を作成することはできません。」** |

カテゴリの新設をユーザー側からリクエストする窓口は、現在Googleに用意されていません（過去のフォーラム経由の要望受付も終了しています）。**待っていても増える見込みは薄い**とお考えください。

### 現在の公開状態（2026-08-25 実機確認）

Google検索で事務所名を検索すると、右側のナレッジパネルに

> 森下知幸税理士・社労士事務所　★5.0　Googleのクチコミ（2）　**大阪市の税理士**

と表示されています。**メインカテゴリは「税理士」**として公開されており、この状態が正解です。
（追加カテゴリは一般ユーザーには表示されないため、外からは「社会保障事務所」の設定有無は見えません）

## 2. 推奨するカテゴリ設定

| 区分 | 設定するカテゴリ | 理由 |
| --- | --- | --- |
| **メイン業種（1つだけ）** | **税理士** | 検索需要が圧倒的に大きく、地図枠の順位を最も左右する。現状のままでOK |
| その他の業種（最大9個・2〜3個に絞るのが効果的） | **社会保障事務所** | 社労士業務に最も近い実在カテゴリ。現状のままでOK |
| 〃 | **会計事務所** | 「会計事務所」で探す方を拾える |
| 〃 | **人事コンサルティング** | 労務相談・就業規則・人事制度の相談を拾える |

### 付けてはいけないカテゴリ

「行政書士」「司法書士」「公認会計士」「弁護士」など、**実際に保有していない資格のカテゴリは絶対に付けないでください**。Googleのガイドライン違反となり、プロフィールの停止（表示消滅）につながります。

### 追加カテゴリを増やしすぎない

その他の業種は最大9個まで設定できますが、**関連の薄いカテゴリを詰め込むとメインカテゴリの評価が薄まります**。上記の3つ程度で十分です。

## 3.「社会保険労務士」という言葉をGoogleに認識させる代替策

カテゴリで表現できない分は、**カテゴリ以外の6か所**で補います。実務上、この6点をやれば「西中島南方　社労士」のような検索にも十分対応できます。

### ① ビジネス名（そのままでOK）

正式名称が「森下知幸税理士・**社労士**事務所」ですので、事務所名の中に既に「社労士」が入っています。**これが一番効いています。**
※ 実際の看板・名刺と違うキーワードを名称に足すのはガイドライン違反です。現状のままにしてください。

### ② ビジネスの説明文（750字）

管理画面の「説明」欄に、社労士業務を具体的に書きます。以下、そのままコピーして貼り付けられる文案です（約340字）。

```
大阪市淀川区西中島、地下鉄「西中島南方」駅から徒歩4分の税理士・社会保険労務士事務所です。
「感謝」を起点に、「尊敬」と「愛」をもって行動する経営理念のもと、記帳代行、税務顧問、決算・確定申告、
法人設立、相続税申告・相続対策までワンストップで承ります。

税理士と社会保険労務士の両方の資格を持つ強みを活かし、給与計算、労働保険・社会保険の手続き、
就業規則の作成・変更、人事労務のご相談まで、税務と労務をまとめてお任せいただけます。
「税理士に聞くこと」と「社労士に聞くこと」を分けずに、窓口ひとつでご相談ください。

初回のご相談は無料です。オンラインでのご相談にも対応しております。まずはお気軽にお問い合わせください。
```

### ③ サービス欄にカスタム項目を追加する（効果が高いのに空欄のことが多い）

管理画面の「サービス」で、カテゴリごとに独自の項目を追加できます。以下をそのまま登録してください。

**税理士のサービスとして**
- 税務顧問
- 記帳代行
- 決算・確定申告
- 法人設立支援
- 相続税申告・相続対策
- 税務調査対応

**社会保障事務所／人事コンサルティングのサービスとして**
- 社会保険労務士業務
- 給与計算
- 労働保険・社会保険の手続き
- 就業規則の作成・変更
- 助成金のご相談
- 人事労務のご相談

（各サービスには説明文も付けられます。「社会保険労務士が対応します」の一文を入れておくと、その語がプロフィール内に増えます）

### ④ 「最新情報」の投稿を月1〜2回

投稿の本文にも語句が反映されます。社労士ネタと税務ネタを交互に出すのがおすすめです。
例：「年度更新（労働保険）の時期です」「社会保険の算定基礎届のポイント」「就業規則、最後に見直したのはいつですか？」

### ⑤ クチコミの本文

**クチコミの中に出てくる言葉もGoogleは読み取ります。** 労務のご相談をされた顧問先には「就業規則」「給与計算」「社会保険」といった言葉が自然に入るようご案内すると効果的です（→ 別紙のクチコミ依頼文をご利用ください）。

### ⑥ ウェブサイト側（当方で対応可能）

現在サイトには「相続」「法人設立」の専用ページはありますが、**社労士業務の専用ページがありません**。
「労務・社会保険のご相談（給与計算・就業規則・労働保険）」のページを1本追加すれば、
Googleがこの事務所を「社労士業務も行う事務所」と判断する材料になります。
**ご希望であればこちらで作成します（お申し付けください）。**

## 4. 設定手順（画面操作）

1. Google検索で「森下知幸税理士・社労士事務所」または「マイビジネス」と検索（森下様のGoogleアカウントでログインした状態）
2. 検索結果上部に出る自分の店舗の管理パネルから **「プロフィールを編集」** をクリック
3. **「ビジネス情報」→「業種」** タブを開く
4. **「ビジネス カテゴリ」**（メイン業種）が「税理士」になっているか確認
5. **「その他のカテゴリ」** の「カテゴリを追加」から、`社会保障事務所` / `会計事務所` / `人事コンサルティング` を検索して追加
6. 「保存」をクリック（反映まで数分〜数時間かかることがあります）
7. 続けて左メニューの **「説明」** に §3-② の文章を貼り付け、**「サービス」** に §3-③ の項目を登録

> ※ 手順1〜7は**オーナー権限のあるGoogleアカウント（森下様）でのみ実行できます**。当方には権限がないため代行できません。
> 画面共有しながらのご案内も可能ですので、必要でしたらお申し付けください。
