# Decisions

AIOS の Auto Decision Policy に基づく**自動判断の履歴**。
人間確認が必要な重大事項（課金 / secret / 本番公開 / 破壊的変更 / 法務 / 個人情報 /
大きな仕様変更 / ブランド大幅変更 / 顧客確認）は自動判断しない（`docs/AUTO_DECISION_POLICY.md`）。

各判断は以下の形式で記録する。

```
### <日付> — <判断内容>

- 採用した方針:
- 理由:
- 代替案:
- 人間確認が不要と判断した理由:
```

### 2026-07-28 — 「感謝・尊敬・愛」SEO対策として経営理念の静的専用ページを新設

- 採用した方針: `philosophy.html` を静的HTMLで新規作成し、index側はメタ情報・構造化データ・内部リンクで補強する
- 理由: 現サイトはJSでコンポーネントを後読みするSPA構成で、理念テキストがクローラーに拾われにくい。
  キーワードで評価されるには、そのキーワードを主題とする独立URLと十分な本文量が必要。
- 代替案: (a) index.htmlのメタ情報だけ変更（コンテンツ量が足りず効果が薄い）
  (b) 理念テキストをindexに静的直書き（SPA構成と二重管理になり崩れやすい）
- 人間確認が不要と判断した理由: 既存ページの削除・仕様変更を伴わない追加のみで、
  文言は森下様から支給された原文をそのまま使用（改変なし）。料金・法的表現の変更も含まない。

### 2026-07-28 — 検証用一時ファイル `_t_*.html` をリポジトリから除外

- 採用した方針: `git rm --cached` で追跡解除し、`.gitignore` に `_t_*.html` を追加（ローカルには残す）
- 理由: 表示確認用のレンダリング断片が公開されると、about/accessと同一内容の重複コンテンツとなりSEO上マイナス
- 代替案: robots.txtでDisallow（公開自体は残るため不十分）
- 人間確認が不要と判断した理由: 未pushの状態で一度も公開されておらず、ローカルファイルは削除していないため復元可能
