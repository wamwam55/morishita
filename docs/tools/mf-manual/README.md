## 生成方法

```bash
python3 -m venv /tmp/_docvenv && /tmp/_docvenv/bin/pip install python-docx
cd docs/tools/mf-manual && /tmp/_docvenv/bin/python assemble.py
# → ~/Downloads/マネーフォワード会計_かんたん操作マニュアル_2026-08.docx
```

PDF が必要なときは Pages で開いて書き出す（この Mac に LibreOffice / pandoc / Word は無い）。
`open -a Pages <docx>` → 12秒ほど待つ → `export front document to POSIX file … as PDF`。
`tell application "Pages" to set d to open …` は `-609 接続が無効です` で落ちることがあるので
`open -a` を使う。

## 内容の根拠

画面名・ボタン名は **マネーフォワード公式サポート（biz.moneyforward.com/support/）を
2026-08-05 に実取得して確認済み**。以下は特に間違えやすく、確認の結果わかったこと。

- **クラウド会計に「消込」というメニューは存在しない。** 正式な機能名は「**予定実現**」、
  ボタンは「**実現**」。［消込］というメニューを持つのは別サービスの「クラウド債権管理」。
  クラウド請求書側の機能名は「入金確認」でボタンは「消し込む」
- **「口座振替」という専用メニューも存在しない。** 自社口座間の資金移動も銀行引落しも通常の仕訳。
  両口座を連携していると二重計上するので、片方を［対象外］にする（公式の日常仕訳ナレッジに明記）
- 入力ルールの正式名は「**自動仕訳ルール**」。「自動登録ルール」は freee の名称であり MF には無い。
  さらに「（通帳カード）」と「（ビジネス）」で**別管理**
- 主要メニューは ［データ連携］［自動で仕訳］［手動で仕訳］［会計帳簿］［各種設定］
- 一覧からの［登録］と［詳細］画面からの登録で**反映項目が違う**（取引先・部門は詳細からのみ）
- API連携は **30〜100日で認可が失効**する。明細が止まる原因の筆頭
- AI-OCR はアプリが **JPEGのみ**、Web版が PDF/JPEG/PNG・最大50MB。**従量課金**
