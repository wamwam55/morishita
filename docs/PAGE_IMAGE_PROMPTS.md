# Page Image Prompts

主要ページの UI 画像を生成するプロンプト雛形（ChatGPT 画像生成 / Claude Design）。
Design Board のトーン・配色・導線に一貫させる。secret / 個人情報は書かない。
正本: AIOS `docs/PAGE_IMAGE_GENERATION_WORKFLOW.md`。

## 共通の前提（各プロンプト先頭に付ける）

```
プロダクト: <名称> / 対象: <対象ユーザー> / トーン: <トーン>
Design Board（design/assets）と配色・タイポ・導線を一致させる。
出力は1ページの UI ワイヤー/デザイン画像。テキストは日本語。個人情報・secret は入れない。
```

## TOP（ホーム / ランディング）

```
上記前提で、TOP ページのデザイン画像を作成。
セクション: <ヒーロー / 特徴 / 料金 / 実績 / CTA / フッター など>。
主要 CTA <例: 体験予約> をファーストビューと下部に。情報階層が明確な1枚。
```

## 下層ページ（About / 料金 / 特徴 等）

```
上記前提で、<ページ名> の下層ページ画像を作成。
見出し + 本文 + 図 + CTA の構成。TOP とヘッダー/フッターを共通化した見た目。
```

## 一覧ページ（リスト / カード一覧）

```
上記前提で、一覧ページ画像を作成。
カード or 行リスト、フィルタ/並び替え、ページネーション。1件の要素は
<例: 画像/タイトル/曜日/価格/詳細ボタン>。詳細ページへの導線を示す。
```

## 詳細ページ（1件詳細）

```
上記前提で、詳細ページ画像を作成。
主要情報（<例: タイトル/画像/曜日・時間/説明/価格>）+ 主要 CTA <例: 予約>。
関連/戻る導線を含む。
```

## フォーム（予約 / 問い合わせ / 登録）

```
上記前提で、フォームページ画像を作成。
入力項目 <例: 氏名/連絡先/希望曜日/メッセージ>、バリデーション表示、送信 CTA、
送信完了状態。個人情報の実値は入れずプレースホルダ表記。
```

## 生成後
- `design/assets/<page>.png` に保存 → Design Board と一致確認 → Claude Design 変換（`CLAUDE_DESIGN_PROMPT.md`）。
